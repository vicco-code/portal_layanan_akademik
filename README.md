## 🛠️ Fitur Utama & Spesifikasi Tugas
1. **Struktur HTML Semantik:** Menggunakan landmark utama (`header`, `nav`, `main`, `section`, `footer`) dan hierarki heading yang logis.
2. **Tiga Kartu Layanan:** Menyediakan minimal 3 kartu layanan akademik (Surat Aktif Kuliah, Transkrip Sementara, Legalisir Dokumen).
3. **Formulir Permohonan:** Memiliki field nama, email kampus, jenis layanan (dropdown), dan keperluan (textarea) dengan validasi HTML native (`required`) serta tombol `<button>` yang valid.
4. **Desain Responsif (Mobile-First):** Dibangun menggunakan CSS Flexbox/Grid agar nyaman diakses pada berbagai ukuran layar tanpa *horizontal scroll*.
5. **Aksesibilitas Dasar:** Mendukung navigasi *keyboard* dengan indikator fokus (*visible focus*) yang jelas.
